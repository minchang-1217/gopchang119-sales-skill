# 곱창119 매출 자동 정리

이 스킬은 두 가지 모드가 있다.

- **설정 모드**: 사용자가 "매출 정리 설정", "처음 설정"이라고 하거나 `config.json`이 없을 때.
- **실행 모드**: 그 외 모든 경우("어제 매출 입력해줘", 자동 실행 등).

설정 파일 위치: `~/gopchang119-sales/config.json` (Windows: `C:\Users\<사용자>\gopchang119-sales\config.json`)
로그 위치: `~/gopchang119-sales/logs/<날짜>.md`

## 절대 규칙 (두 모드 공통)

1. 브라우저 작업은 **Aside MCP**(`mcp__aside__repl`)로만 한다.
2. 각 사이트에서는 **읽기만** 한다. 설정 변경, 광고·할인 조작, 충전, 주문 접수/취소, 리뷰 답글은 절대 하지 않는다.
3. **로그인은 절대 대신 하지 않는다.** 아이디·비밀번호·보안문자를 입력하지 않고, 로그인 버튼도 누르지 않으며, 다른 에이전트(`mcp__aside__exec` 등)에게 로그인을 시키지도 않는다. 로그인 화면이 나오면 사장님에게 "어사이드 브라우저에서 ○○에 직접 로그인해 주세요"라고 알리고 그 채널은 건너뛴다.
4. 값을 확인할 수 없으면 칸을 **비워 둔다**. 추측해서 넣지 않는다.
5. 시트에서 **이미 값이 있는 칸(0 포함)은 절대 덮어쓰지 않는다.**
6. 작업이 끝나면 내가 연 탭은 모두 닫는다. 사장님이 원래 열어 둔 탭은 건드리지 않는다.
7. 사용자에게는 쉬운 한국어로, 전문용어 없이 설명한다.

## 설정 모드

처음 쓰는 사장님도 따라올 수 있게 **한 번에 하나씩** 묻고 확인한다.

### 1단계 — 준비물 확인
- `mcp__aside__repl`로 `listBrowserTabs()`를 실행해 Aside가 연결됐는지 본다. 실패하면 README의 "2. 어사이드 연결" 단계를 안내하고 멈춘다.

### 2단계 — 매장 정보
묻기: 매장 이름(예: 곱창119 ○○점), 영업 마감 시각(예: 02:00), 홀 하루 기준 시각(기본 06:00 — 새벽 6시 전 결제는 전날 매출로 봄).

### 3단계 — 사용하는 채널 고르기
아래 표에서 매장이 쓰는 채널을 고르게 한다. 고른 채널마다 Aside에서 사이트를 **열어서** 로그인돼 있는지와 매장 고유번호(URL 속 숫자)를 직접 찾아 config에 저장한다. 로그인 안 돼 있으면 사장님에게 직접 로그인해 달라고 하고 기다린다(대신 로그인 금지).

| 키 | 채널 | 시작 주소 | 찾을 값 |
|---|---|---|---|
| baemin | 배달의민족 | https://self.baemin.com/orders/history | (없음) |
| coupang | 쿠팡이츠 | https://store.coupangeats.com/merchant/management/orders | 주소 끝 매장번호 → `orders/<번호>` |
| yogiyo | 요기요 | https://ceo.yogiyo.co.kr/order-history/list | (없음) |
| ddangyo | 땡겨요 | https://boss.ddangyo.com (주문/정산 → 주문내역) | (없음) |
| naver_order | 네이버 주문 | https://partner.booking.naver.com → 주문 목록 | 주소 속 `bizes/<번호>` |
| toss_hall | 토스플레이스 포스(홀·전화) | https://dashboard.tossplace.com → 결제 내역 | 주소 속 `m/<번호>` |

다른 포스(OK POS, 페이히어 등)를 쓰는 매장은 그 포스의 결제 내역 화면을 같이 열어 보고, 어디서 금액을 읽을지 사장님과 정해서 `extra_channels`에 적는다.

### 4단계 — 구글 시트
- 사장님 시트가 이미 있으면 주소와 탭 이름을 받고, Aside로 열어 **열 구성을 읽어** 각 채널이 몇 번째 열인지 사장님에게 확인받는다.
- 시트가 없으면 `templates/매출시트_양식.csv`를 안내한다: 구글 드라이브 → 새로 만들기 → 구글 시트 → 파일 → 가져오기 → 업로드. 날짜 행은 PowerShell로 오늘부터 내년 12/31까지 만들어 CSV를 새로 써 줘도 된다(양식의 열 순서 유지).
- 시트는 사장님 구글 계정으로 Aside에 로그인돼 있어야 한다.

### 5단계 — config.json 저장
`templates/config.example.json` 형식대로 저장한다. 저장한 내용을 표로 보여 주고 맞는지 확인받는다.

### 6단계 — 시험 실행
"어제 날짜로 한 번 돌려 볼게요"라고 하고 실행 모드를 한 번 돌린다. 결과 표를 보여 주고, 사장님이 아는 숫자와 맞는지 물어본다.

### 7단계 — 매일 자동 실행 (선택)
`scripts/install_schedule.ps1`을 **사장님이 직접** 실행하도록 안내한다(관리자 권한 PowerShell에서 `powershell -ExecutionPolicy Bypass -File install_schedule.ps1`). 내가 대신 작업 스케줄러를 바꾸지 않는다. 기본 시각은 마감 30분 뒤이며, PC가 그 시각에 켜져 있어야 한다.

## 실행 모드

`config.json`을 읽는다. 대상 날짜 **D** = 사용자가 말한 날짜, 없으면 **어제**(한국 시간). 새벽 자동 실행이면 실행 날짜의 하루 전.

### 1. 값 수집 (D 하루치, 원 단위 정수)

| 채널 | 읽는 값 | 기준 |
|---|---|---|
| 배민 | 주문내역의 **결제금액** 합 | 주문시각이 달력 날짜 D(00:00~23:59). 취소 제외. 모든 페이지 확인 |
| 쿠팡이츠 | 주문 목록의 **매출액** 합 | 주문일이 D. 상태 "주문취소" 제외. 모든 페이지 |
| 요기요 | 주문내역의 **주문금액** 합 | 주문시각이 D, 상태 "성공"만 |
| 땡겨요 | 주문내역의 **결제금액** 합 | 주문일시가 D, 상태 "주문완료"만 |
| 네이버 주문 | 결제금액 합 | 기간 "7일", 상태 "전체"로 조회 후 접수일시가 D이고 "완료"인 것. 없으면 0 |
| 토스 홀 | 결제 내역의 **결제금액** 합 | 기간 "이번 달"(D가 지난달이면 "지난달"), 주문채널 "포스", 상태 "완료". 결제시간이 **D 기준시각(기본 06:00) ~ D+1 기준시각 전**. "취소됨" 표시가 있어도 상태가 "완료"면 포함(취소 후 재결제) |
| 홀 객(팀)수 (설정한 경우) | 토스 "포스·완료" 결제 **건수** | D 영업 시작 ~ D+1 마감 |

- 배달앱은 모두 **할인 후 결제금액** 기준이다.
- 목록이 여러 페이지면 끝까지 넘긴다. D의 첫 주문과 마지막 주문 바로 바깥 주문까지 확인해 경계를 놓치지 않는다.
- 로그인 화면이 나오면 그 채널은 건너뛰고 나머지를 먼저 한다. 다 끝나면 그 채널만 10분 뒤 다시 열어 보고, 그래도 로그인 화면이면 10분 뒤 한 번 더 본다(최대 2번). 자동 실행(-p)일 때는 턴을 끝내고 기다리지 말고 `await new Promise(r=>setTimeout(r,110000))`를 반복해 도구 안에서 기다린다.

### 2. 시트 입력
- config의 시트·탭을 Aside로 연다. 날짜 열에서 D 행을 찾는다.
- config의 열 매핑대로 **빈 칸에만** 값을 넣는다. 값이 있는 칸이 수집 값과 다르면 덮어쓰지 말고 로그에 차이만 적는다.
- 합계·월합계 등 수식 칸과 그 밖의 열은 건드리지 않는다.
- 실패한 채널이 있고 비고 열이 비어 있으면 `자동입력 실패: 땡겨요`처럼 채널 이름만 적는다.
- 입력 후 그 행을 **다시 읽어** 제대로 들어갔는지 확인한다.
- **밀린 칸 채우기**: D 이전 10일 중 빈 칸이 있으면 지금 로그인된 채널에 한해 같은 기준으로 채우고, 비고의 `자동입력 실패` 표시에서 그 채널 이름을 지운다.

### 3. 로그와 보고
`logs/<D>.md`에 채널별 금액·건수(가능하면 주문 시각·금액 목록), 새로 입력한 칸, 건너뛴 칸, 실패 채널과 이유, 기존 값과의 차이를 적는다.
사용자에게는 짧은 표로 보고한다. 값이 0인 채널(특히 홀)은 "휴무였거나 아직 반영 안 됐을 수 있어요"라고 한 줄 덧붙인다.
